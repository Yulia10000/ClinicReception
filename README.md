# ClinicReception

Навчальний проєкт з дисципліни «Конструювання програмного забезпечення».

Варіант №4: запис пацієнтів на прийом до лікаря.

## Предметна область

Проєкт призначений для моделювання записів пацієнтів на прийом до лікаря.

## Склад рішення

* ClinicReception.Core — логіка предметної області;
* ClinicReception.App — консольний застосунок.

## Вимоги

* .NET SDK 8.0 або новіший;
* Git;
* Visual Studio Community.

## Складання

```text
dotnet build
```

## Запуск

```text
dotnet run --project ClinicReception.App
```

## Перевірка форматування

```text
dotnet format --verify-no-changes
```

## Стандарт кодування

Правила описані у файлі CODING_STANDARD.md та частково закріплені у .editorconfig.
