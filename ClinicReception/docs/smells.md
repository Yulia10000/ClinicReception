# Реєстр дефектів успадкованого коду

| No | Дефект | Місце | Прояв | Рефакторинг |
|---:|---|---|---|---|
| 1 | Довгий список параметрів | Handle() | Метод має 11 параметрів, частина з яких описує одного клієнта | Introduce Parameter Object |
| 2 | Вкладені умови | Handle() | Чотири рівні вкладених if, через що код важко читати | Decompose Conditional, охоронні умови |
| 3 | Тимчасове поле | _tmpSum, _tmpDiscount | Поля класу використовуються лише під час виконання методу Handle() | Remove Temporary Field |
| 4 | Дублювання коду | Handle() і Preview() | В обох методах повторюються обчислення суми, знижки та доставки | Extract Method |
| 5 | Магічні числа | Handle() і Preview() | Використовуються числові значення 0.15, 0.30, 0.05, 500, 1000, 60 без пояснення їх призначення | Replace Magic Number with Constant |
| 6 | Довгий метод | Handle() | Метод виконує перевірку даних, обчислення вартості, формування звіту та запис повідомлень | Extract Method |
| 7 | Примітивна одержимість | clientKind, state | Для визначення типу клієнта та стану документа використовуються звичайні рядки | Introduce Enum |
| 8 | Великий клас | LegacyAppointmentProcessor | Один клас відповідає за обчислення, формування звіту, перевірку даних і журналювання | Extract Class |
